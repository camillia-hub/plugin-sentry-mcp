# Sentry MCP

Reads Sentry issues and events. This plugin installs and configures it in your workspaces.

Upstream server docs: https://www.npmjs.com/package/sentry-mcp

Installs from the Camillia hub as `sentry-mcp-711af0`. On every new task the plugin posts
the ready-to-paste `mcp.servers` entry and the setup steps as a task comment.
